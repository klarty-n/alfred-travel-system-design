# Приёмочные сценарии

Сценарии являются критериями проверки будущей реализации. Выполнение сценариев работающим сервером пока не подтверждено

| ID | Требования | Условие и действие | Ожидаемый результат |
|---|---|---|---|
| A-01 | F-01 | Тот же номер в другую дату или с другим исходным временем | Другой рейс; неизвестный ключ сохранён как unmatched |
| A-02 | F-02, N-01 | Повтор provider/event с тем же payload; затем с другим | Один результат и inbox; изменённый payload получает 409 без перезаписи оригинала |
| A-03 | F-03 | Ревизия 7 приходит после 8 | Актуальное состояние 8 сохранено, старое событие отмечено ignored_stale |
| A-04 | F-03, F-11 | Нет ревизии, равная ревизия противоречит данным или изменён поток; сверка недоступна | Pending, видна свежесть, спорное состояние не применяется |
| A-05 | F-04 | Отмена без фактического прибытия | Транспортный участок требует замены; время прибытия не выдумывается |
| A-06 | F-04 | MCT45 + запас15, интервал 59, затем 60 минут | В первом случае нарушение, во втором пересадка допустима |
| A-07 | F-04, F-05 | Подтверждённая задержка, все окна достижимы | Уведомление о статусе сохранено, ложных последствий и поиска нет |
| A-08 | F-05, N-01 | Пользователь оффлайн, push падает, обработчик перезапускается | Одно сообщение в inbox, доставка повторяется, после входа доступен актуальный план |
| A-09 | F-06, F-07 | Недостаточный багаж, мест меньше группы или неизвестно право одного участника | Кандидат исключён до ранжирования с конкретной причиной |
| A-10 | F-06, F-07, F-12 | Пропущена активность, недостижимы окна отеля и трансфера | Подбор допустимой активности; действия по броням; активность не объявляется заменой перелёта |
| A-11 | F-08 | Предложение истекло, изменились цена/багаж или за время revalidation изменился рейс/план | 409 с причиной, версия и брони не изменены |
| A-12 | F-08, F-11 | Revalidation недоступна | 503, версия не создана; при сбое поиска отдельное состояние temporarily_unavailable |
| A-13 | F-09 | Два выбора с одной expected_plan_version | Только одна новая версия, второй запрос 409/current_version |
| A-14 | F-09 | Повтор успешного ключа после expiry; тот же ключ с другим телом | Сохранённый ответ без новой версии; другое тело 409 |
| A-15 | F-10, N-04 | Чужой trip_id; чужой impact/offer; участник без can_confirm | 404 без утечки данных; своему участнику без права подтверждения 403 |
| A-16 | N-02 | Перелёт через полночь, разные зоны, неоднозначное время DST | Сравнения по UTC; неоднозначное местное время требует уточнения |
| A-17 | N-03 | Passport-поле во входном событии | 422, поле не записано в БД и логи |
| A-18 | N-01 | Сбой после commit до ответа; сбой после обновления Flight до обработки поездки | Повтор возвращает сохранённый результат; устойчивая задача завершает последствия без дублей |
| A-19 | F-11 | Webhook пропущен; поставщик восстановился | Опрос получает изменение, проходит общую обработку; повтор оператором безопасен |
| A-20 | F-08, F-09 | Выбран новый перелёт, бронирование ещё не выполнено | Новый план содержит needs_booking; старые брони не отменены, история сохранена |
| A-21 | N-05 | 1000 событий при 10 событиях/с после прогрева | p95 received→inbox не более 5 с; задержка источника измерена отдельно |

Полный пример A-06, A-08, A-09 и A-13 приведён в [разборе поездки](example.md)
