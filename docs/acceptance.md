# Приёмочные сценарии

Сценарии являются критериями проверки будущей реализации

| ID | Требования | Условие и действие | Ожидаемый результат |
|---|---|---|---|
| A-01 | F-01 | Тот же номер в другую дату или с другим исходным временем | Другой рейс; неизвестный ключ сохранён как unmatched |
| A-02 | F-02, N-01 | Повтор provider/event с тем же payload; затем с другим | Один результат и inbox; изменённый payload получает 409 без перезаписи оригинала |
| A-03 | F-03 | Ревизия 7 приходит после 8 | Актуальное состояние 8 сохранено, старое событие отмечено ignored_stale |
| A-04 | F-03, F-11 | Нет ревизии, равная ревизия противоречит данным или изменён поток; сверка недоступна | Pending, видна свежесть, спорное состояние не применяется |
| A-05 | F-04 | Отмена без фактического прибытия | Транспортный участок требует замены; время прибытия не выдумывается |
| A-06 | F-04 | MCT45 + запас15, интервал 59, затем 60 минут | В первом случае нарушение, во втором пересадка допустима |
| A-07 | F-04, F-05, F-06 | Подтверждённая задержка, маршрут выполним, до посадки нет свободного окна | Уведомление о статусе сохранено, план прежний, подбор не запущен |
| A-08 | F-05, N-01 | Пользователь оффлайн, push падает, обработчик перезапускается | Одно сообщение в inbox, доставка повторяется, после входа доступен актуальный план |
| A-09 | F-06, F-07 | Багаж не обеспечен даже с подтверждёнными опциями, мест меньше группы или неизвестно право одного участника | Кандидат исключён до ранжирования с конкретной причиной |
| A-10 | F-06, F-07, F-12 | Пропущена активность, недостижимы окна отеля и трансфера | Подбор допустимой активности; действия по броням; активность не объявляется заменой перелёта |
| A-11 | F-08 | Предложение истекло, изменились цена/багаж или за время revalidation изменился рейс/план | 409 с причиной, версия и брони не изменены |
| A-12 | F-08, F-11 | Revalidation недоступна | 503, версия не создана; при сбое поиска отдельное состояние temporarily_unavailable |
| A-13 | F-09 | Два выбора с одной expected_plan_version | Только одна новая версия, второй запрос 409/current_version |
| A-14 | F-09 | Повтор успешного ключа после expiry; тот же ключ с другим телом | Сохранённый ответ без новой версии; другое тело 409 |
| A-15 | F-10, N-04 | Чужой trip_id; чужой impact/offer; участник без can_confirm | 404 без утечки данных; своему участнику без права подтверждения 403 |
| A-16 | N-02 | Перелёт через полночь, разные зоны, неоднозначное время DST | Сравнения по UTC; неоднозначное местное время требует уточнения |
| A-17 | N-03 | Passport-поле во входном событии | 422, поле не записано в БД и логи |
| A-18 | N-01 | Сбой после commit до ответа; сбой после обновления Flight до обработки поездки | Повтор возвращает сохранённый результат; устойчивая задача завершает последствия без дублей |
| A-19 | F-11 | Webhook пропущен; поставщик восстановился | Опрос получает изменение, проходит общую обработку; повтор оператором безопасен |
| A-20 | F-08, F-09 | Выбран новый перелёт, бронирование ещё не выполнено | Новый план содержит needs_booking; старые брони не отменены, история сохранена |
| A-21 | N-05 | 1000 подтверждённых изменений при 10 событиях/с после прогрева; по одной поездке с тремя участниками на рейс, без сверки | Все ожидаемые Inbox сохранены без дублей; p95 от received_at до записи последнего Inbox по событию ≤ 5 с; задержка источника измерена отдельно |
| A-22 | F-11, N-01 | Повторное подключение и старый контекст TravelTech | Одна версия 1, старый контекст не откатывает ограничения или маршрут |
| A-23 | F-08, F-09, F-10 | После выдачи offer изменились ограничения, can_confirm или участник удалён | Старое предложение получает 409, отозванное право 403, удалённому участнику 404; повтор доставки ему запрещён |
| A-24 | F-06, F-07 | Пока Search отвечал, изменились план или исходный рейс | Старый результат не публикуется, назначается актуальный поиск |
| A-25 | F-03 | Во время Status.current применено более новое событие | Ответ сверки повторно сравнивается под блокировкой, состояние не понижается |
| A-26 | F-03, F-04 | Назначенный источник подтвердил исправление отмены | Новое состояние принято, последствия пересчитаны, исчезнувшие нарушения resolved |
| A-27 | F-09, F-11 | Booking подтвердил новый элемент needs_booking по trip_id и plan_item_id, затем прислал тот же факт и запоздалый факт по архивному элементу | Текущий элемент получает booking_ref и booked в новой версии. Повтор версии не создаёт. Запоздалый факт не меняет текущий план и виден для разбора |
| A-28 | F-02, F-03 | В одном потоке после задержки в ревизии 7 пришла ревизия 9 с теми же данными, затем ревизия 8 с отменой | Сохранена ревизия 9. Отмена получает ignored_stale. Поля state_version, current_event_id и inbox остаются прежними |
| A-29 | F-03, F-10, N-04 | Чужой provider_id в токене/теле; событие неназначенного источника | 403 при несоответствии токена; иной источник не меняет состояние без сверки |
| A-30 | F-06, F-07 | Сроки предложений истекли, в том числе valid_until обязательного разрешения при ещё действующем тарифе | Истёкшие варианты исключены. При истечении всей выдачи виден searching до результата фонового обновления |
| A-31 | F-11, N-01 | БД недоступна при приёме или чтении | 503 без ложного подтверждения приёма; повтор после восстановления безопасен |
| A-32 | N-01 | Lease истёк, два worker выполняют одну задачу | Один бизнес-эффект/inbox, завершение по актуальному lease; ограничение повторов push явно учтено |
| A-33 | F-04, F-07 | Неизвестны место, MCT, время или актуальность права на маршрут | Needs_information, неподтверждённый вариант не признан допустимым |
| A-34 | F-04, F-05, F-10 | Один рейс принадлежит двум поездкам с разными ограничениями | Раздельные последствия и адресаты, сбой одной поездки не теряет задачу другой |
| A-35 | F-11, N-01 | Сбой загрузки страницы контекста; затем поездка отключена | Страница не пропущена; контрольная задача сохраняет cursor между циклами и не очищается как done; задачи отключённой поездки останавливаются, общий рейс другой поездки отслеживается |
| A-36 | F-04, F-05, N-01 | Новая поездка подключена к уже задержанному рейсу; нового события нет | Последствия и уведомления рассчитаны по сохранённому подтверждённому состоянию, опрос не является условием пересчёта |
| A-37 | F-05, F-09, N-01 | Чтение во время подтверждения и поздний commit уведомления | План согласован по одному снимку, cursor по sequence_no не теряет сообщение следующей страницы |
| A-38 | F-06, F-07 | Один кандидат и одинаковые ограничения в обычном поиске и восстановлении | Общие проверки предложения и маршрута дают одинаковое решение по одинаковым данным; отдельной копии правил в Alfred нет |
| A-39 | F-06, F-07 | Допустимые кандидаты ранжируются с DISCOVERY и RECOVERY; повтор с теми же данными | Политики могут дать разный порядок; одна политика детерминирована, ID разрешает полное равенство |
| A-40 | F-07, F-08 | Включено 15 кг, требуются 23; поставщик подтвердил допопцию до 25 кг с ценой | Вариант проверяется с нормой 25 кг и полной ценой группы; неизвестная цена/доступность опции не считается допустимостью |
| A-41 | F-06, F-11 | Первая страница не подходит, следующая содержит подходящий вариант; часть источников не ответила | Пагинация продолжается, неполнота видна через search_complete=false; ложного none_eligible нет |
| A-42 | F-07, F-09, F-12 | Новый перелёт требует изменения старого трансфера/брони | required_actions видны до выбора; needs_change/needs_booking не выдаются за booked или полностью восстановленный план |
| A-43 | F-08, F-09 | Между показом и выбором изменились rules_version, условия допбагажа или основание варианта | Те же общие правила применены заново; 409 без новой версии, изменённые условия требуют нового выбора |
| A-44 | F-04, F-07 | Внутри предложения пересадка подходит, но стыковка с сохраняемым рейсом/активностью нарушена | Общие правила маршрута проверяют весь проект замены, нарушение не скрывается локальной пригодностью одного участка |
| A-45 | F-07, F-08 | Результат проверки маршрута актуален, но разрешение не применимо к дате поездки; затем истёк valid_until проверки | В обоих случаях допустимость не подтверждена, требуется актуальная проверка |
| A-46 | F-06, F-07, F-11 | После нового search_id пришла страница прежнего запуска с теми же версиями плана/рейса | Старый ответ не публикуется и не смешивается с новой выдачей; cursor и полнота относятся к текущему запуску |
| A-47 | F-04, F-09, N-01 | Пересчёт рейса уже завершён; состав группы или багаж изменён, состояние рейса прежнее | Новая plan_version входит в dedup_key; новый пересчёт выполняется, повтор этой же задачи не дублирует результат |
| A-48 | F-08, F-09 | Один участок заменён несколькими; старая бронь подтверждена с задержкой | Новые ID и текущая цепочка сохранены атомарно; старые элементы is_current=false, ссылки истории действуют, GET не возвращает их в текущий план |
| A-49 | F-06, F-11, N-01 | Поиск проходит две страницы с повтором; затем завершённая задача очищена | Та же задача возобновляется по search_id; cursor и Offer не дублируются, SearchRun и выдача доступны после очистки очереди |
| A-50 | N-01, N-05, F-05, F-11 | После прогрева 100 подтверждённых изменений/с в течение 60 с, без сверки. По одному изменению на рейс и одной поездке с тремя участниками на рейс. В середине пика одно событие заменено отменой рейса в 100 поездках по три участника. Поиск недоступен, задачи доставки выполняются параллельно | Все 6000 событий приняты с 202, все ожидаемые Inbox записаны без дублей. p95 до последнего Inbox по событию ≤ 5 с, по массовой отмене 100 пересчётов и 300 Inbox за ≤ 30 с. Отказ поиска виден в выдаче. По завершении пика измерено время возврата очередей к обычному уровню |
| A-51 | F-06, F-07, F-11 | Для сохранённой выдачи изменились план, состояние исходного рейса или правила. GET пришёл до пересчёта, затем последствие закрыто | До готовности актуального результата 200/searching с пустым offers и search_complete=false. После закрытия 404. Старые варианты и полнота прежнего поиска не выдаются |
| A-52 | F-05, F-06, F-07, F-09 | При задержке маршрут выполним. Группа в зоне посадки, активность закончится в 18:00, дорога и запас по 10 мин, явка до 18:20 | Уведомление сохранено до выдачи. Создан waiting_activity, вариант проходит проверку на границе окна. План меняется после выбора, перелёт сохранён |
| A-53 | F-05, F-06, F-07 | Вылет отложен на час, крайнее время явки неизвестно или наблюдение устарело | Сохранено уведомление, поиск активности не запущен. Ожидаемое время вылета не используется как граница |
| A-54 | F-06, F-07, F-08 | Выдана активность из A-52. Граница посадки сдвинулась с 18:20 на 18:15 при прежнем времени вылета | state_version увеличена, старый вариант скрыт до пересчёта. Подтверждение старого offer получает 409, план не меняется |
